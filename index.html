网站案例

五个不同类型的网站：咖啡品牌官网、B2B 软件官网、AI SaaS 产品页、摄影师个人作品集、旅行社服务页。都能直接点开浏览，交互和动效是真实可用的，不是截图；桌面和手机都适配。

咖啡 · 餐饮品牌官网

焙序咖啡

整站围绕「烘焙曲线」：首屏的曲线按真实升温速率逐秒画出来，豆温和阶段读数同步跳动。往下的豆单做成豆包标签，烘焙度滑块一拖，豆子颜色和风味描述跟着变。

结构
首屏 · 本季豆单 · 烘焙度 · 菜单 · 门店 · 订阅 + 页脚
技术
原生 HTML / CSS / JS，SVG 曲线 + requestAnimationFrame

企业官网 · B2B 软件

仓衡 WMS

首屏是一个用代码画出来的仓库：拣货员沿通道拣货、回台复核，出库单数实时增加。四个核心功能做成可切换的界面样机，底部是带完整校验的预约演示表单。

结构
首屏 · 客户 · 产品功能 · 数据 · 行业方案 · 客户案例 · 部署 · 价格 · 预约演示 + 常见问题
技术
原生 HTML / CSS / JS，SVG 实时绘制，无障碍分页签

旅行社 · 本地服务业

Airlines

首屏是镜头穿过舷窗的视频。往下所有照片都框在舷窗形状里；结尾的晚霞随滚动从一扇舷窗慢慢放大到整屏，和首屏首尾呼应。

结构
首屏 · 关于 · 目的地轨道 · 服务 · 本月目的地 · 常见问题 · 结尾
技术
